# Logofy > AI-Powered Logo Generator

Logofy is a full-stack Next.js application that generates professional logos using AI.
Built with cutting-edge AI models and modern web technologies, it demonstrates AI integration, authentication, payment processing, and real-time image generation.
### **Live:** [Logofy](https://logofyy.vercel.app/)

## Features  

- AI Logo Generation – Premium logos via Replicate's Hyper-Flux-8step model (8-10s generation)
- Free Tier – Generate logos with Pollinations.ai for non-premium users
- Authentication – Secure login/signup via Clerk
- Payment Integration – Razorpay for premium plan subscriptions
- Credit System – Track and manage user credits
- Logo Dashboard – View and manage all generated logos
- Cloud Storage – Integrated with Supabase for permanent logo storage
- Responsive UI – Built with Tailwind CSS and shadcn/ui components
- Toast Notifications – Real-time feedback with React Hot Toast

## Setup Instructions

### Prerequisites

- Node.js 18+ & npm installed
- Supabase account (database & storage)
- Clerk account (authentication)
- Replicate API account (premium logo generation)
- Razorpay account (payment processing)
- Resend account (email notifications)
- Google AI Studio account (Gemini API)

#### 1. Clone the repo
```
git clone https://github.com/Piyush-20045/logofy.git
cd logofy
```

#### 2. Install dependencies
```
npm install
```

#### 3. Create a .env.local file in the root directory
```
# CLERK CREDENTIALS
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_clerk_publishable_key
CLERK_SECRET_KEY=your_clerk_secret_key
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in

# SUPABASE CREDENTIALS
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key

# AI API KEYS
GEMINI_API_KEY=your_gemini_api_key
REPLICATE_API_TOKEN=your_replicate_api_token

# RAZORPAY CREDENTIALS
RAZORPAY_KEY_ID=your_razorpay_key_id
RAZORPAY_KEY_SECRET=your_razorpay_key_secret
NEXT_PUBLIC_RAZORPAY_KEY_ID=your_razorpay_key_id

# RESEND API KEY(CONTACT FORM)
RESEND_API_KEY=your_resend_api_key
```

#### 4. Set up Supabase Database
Create the following tables in your Supabase project:
Users Table:
```
create table public.users (
  id text not null,
  name text null,
  email text not null,
  credits integer null default 5,
  created_at timestamp without time zone null default now(),
  plan_type text not null default 'free'::text,
  constraint users_pkey primary key (id),
  constraint users_email_key unique (email)
) TABLESPACE pg_default;
```
Logos Table:
```
create table public.logos (
  created_at timestamp with time zone not null default now(),
  title text null,
  "desc" text null,
  image_url text null,
  user_id text not null,
  id bigint generated by default as identity not null,
  constraint logos_pkey primary key (id),
  constraint logos_user_id_fkey foreign KEY (user_id) references users (id)
) TABLESPACE pg_default;
```
Payments Table
```
create table public.payments (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  payment_id text not null,
  order_id text not null,
  user_id text not null,
  constraint payments_pkey primary key (id),
  constraint payments_user_id_fkey foreign KEY (user_id) references users (id)
) TABLESPACE pg_default;
```
Storage Bucket:
- Create a bucket named generated-logos
- Set it to public for logo access

#### 5. Run the development server
```
npm run dev
```

## Key Implementation Highlights
### State Management
**Challenge**: Form data lost between steps <br />
**Solution**: Used Zustand with persist middleware for cross-step state persistence

### Image Processing & Storage
**Challenge**: AI returned binary data, Supabase needed ArrayBuffer format <br />
**Solution**: Converted binary → base64 → ArrayBuffer using base64-arraybuffer package

### Premium Credit System
**Challenge**: Needed free vs premium tier workflow <br />
**Solution**: Built credit-based routing – free users → Pollinations.ai, premium users → Replicate (with auto-downgrade when credits = 0)

### Payment Integration
**Challenge**: Stripe unavailable in India <br />
**Solution**: Integrated Razorpay with crypto signature verification

### Race Condition
**Challenge**: Credit fetch failed for new users before DB sync <br />
**Solution**: Retry logic with exponential backoff (500ms, 1s, 2s delays)
